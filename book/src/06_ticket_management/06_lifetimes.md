# ライフタイム (Lifetimes)

`for` ループで最大限便利に使えるように、`&TicketStore` に対して `IntoIterator` の実装を追加して、前回の演習を完成させてみましょう。

まずは、実装の中で最も「自明な」部分を埋めることから始めます：

```rust
impl IntoIterator for &TicketStore {
    type Item = &Ticket;
    type IntoIter = // ここには何が入るでしょうか？

    fn into_iter(self) -> Self::IntoIter {
        self.tickets.iter()
    }
}
```

`type IntoIter` には何を設定すべきでしょうか？\
直感的には、`self.tickets.iter()` によって返される型、つまり `Vec::iter()` によって返される型になるはずです。\
標準ライブラリのドキュメントを確認すると、`Vec::iter()` は `std::slice::Iter` を返すことがわかります。
`Iter` の定義は次の通りです：

```rust
pub struct Iter<'a, T> { /* フィールドは省略 */ }
```

`'a` は**ライフタイムパラメータ (lifetime parameter)** です。

## ライフタイムパラメータ

ライフタイムとは、参照（可変または不変）がどのくらいの期間有効であるかを追跡するためにRustコンパイラが使用する**ラベル**です。\
参照のライフタイムは、それが指し示す値のスコープによって制約されます。ダングリングポインタや解放後使用（use-after-free）バグを回避するため、Rustは参照先の値がドロップされた後に参照が使用されないことを、コンパイル時に常に確認します。

これには聞き覚えがあるはずです。所有権と借用について議論したときに、これらの概念が実際に機能しているのをすでに見ました。
ライフタイムとは、特定の参照がどのくらいの期間有効であるかに**名前を付ける**ための方法に過ぎません。

複数の参照があり、それらが**互いにどのように関連しているか**を明確にする必要がある場合に、名前を付けることが重要になります。
`Vec::iter()` のシグネチャを見てみましょう：

```rust
impl <T> Vec<T> {
    // 少し簡略化しています
    pub fn iter<'a>(&'a self) -> Iter<'a, T> {
        // [...]
    }
}
```

`Vec::iter()` は `'a` という名前のライフタイムパラメータに関してジェネリックになっています。\
`'a` は、`Vec` のライフタイムと、`iter()` によって返される `Iter` のライフタイムを**結びつける**ために使用されています。
平易な言葉で言えば、`iter()` によって返される `Iter` は、それを作成した元の `Vec` の参照 (`&self`) よりも長生きすることはできない（アウトライブできない）、ということです。

これが重要なのは、先ほど説明した通り、`Vec::iter` が `Vec` の要素への**参照**に対するイテレータを返すからです。
もし `Vec` がドロップされてしまうと、イテレータが返す参照は無効になってしまいます。Rustはこれが起こらないことを保証しなければならず、ライフタイムはこのルールを強制するために使用されるツールなのです。

## ライフタイムの省略 (Lifetime elision)

Rustには、多くのケースで明示的なライフタイム注釈を省略できるようにする**ライフタイム省略規則 (lifetime elision rules)** と呼ばれる一連のルールがあります。
例えば、`std` のソースコード内では、`Vec::iter` の定義は次のようになっています：

```rust
impl <T> Vec<T> {
    pub fn iter(&self) -> Iter<'_, T> {
        // [...]
    }
}
```

`Vec::iter()` のシグネチャには、明示的なライフタイムパラメータが存在しません。
省略規則により、`iter()` によって返される `Iter` のライフタイムは、`&self` 参照のライフタイムに結びつけられていると解釈されます。
`'_` は、`&self` 参照のライフタイムに対する**プレースホルダー**だと考えることができます。

ライフタイムの省略に関する公式ドキュメントへのリンクについては、[参考資料](#参考資料)セクションを参照してください。\
ほとんどのケースでは、明示的なライフタイム注釈を追加する必要があるときにはコンパイラが教えてくれるので、それに頼ることができます。
