# チケット管理 (Ticket Management)

前の章では、単体としての `Ticket` をモデリングしました。つまり、そのフィールドと制約を定義し、それらをRustで最も良く表現する方法を学びましたが、`Ticket` がより大きなシステムの中にどのように組み込まれるかについては考慮していませんでした。
この章では、チケットを保存および取得するための（初歩的な）管理システムを導入し、`Ticket` を中心としたシンプルなワークフローを構築していきます。

この課題を通じて、以下のような新しいRustの概念を探求する機会が得られます：

- スタック割り当ての配列
- 可変長配列型である `Vec`（ベクタ）
- コレクションを反復処理（イテレート）するための `Iterator` と `IntoIterator`
- コレクションの一部を扱うためのスライス (`&[T]`)
- 参照がどのくらいの期間有効であるかを記述するライフタイム
- 2つのキー・バリュー型データ構造である `HashMap` と `BTreeMap`
- `HashMap` 内のキーを比較するための `Eq` と `Hash`
- `BTreeMap` を扱うための `Ord` と `PartialOrd`
- コレクション内の要素にアクセスするための `Index` と `IndexMut`
