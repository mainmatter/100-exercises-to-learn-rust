# スライス (Slices)

`Vec` のメモリレイアウトに戻りましょう：

```rust
let mut numbers = Vec::with_capacity(3);
numbers.push(1);
numbers.push(2);
```

```text
         +---------+--------+----------+
スタック | pointer | length | capacity | 
         |  |      |   2    |    3     |
         +--|------+--------+----------+
            |
            |
            v
         +---+---+---+
ヒープ:  | 1 | 2 | ? |
         +---+---+---+
```

`String` の正体が実は `Vec<u8>` に過ぎないことはすでに述べました。\
この類似性から、「`Vec` における `&str` に相当するものは何だろう？」という疑問が湧いてくるはずです。

## `&[T]`

`[T]` は、型 `T` の連続した要素の並びの**スライス (slice)** です。\
最も一般的には、借用された形式である `&[T]` として使用されます。

`Vec` からスライス参照を作成するには、さまざまな方法があります：

```rust
let numbers = vec![1, 2, 3];
// インデックス構文を使用
let slice: &[i32] = &numbers[..];
// メソッドを使用
let slice: &[i32] = numbers.as_slice();
// あるいは要素の一部（サブセット）に対して
let slice: &[i32] = &numbers[1..];
```

`Vec` はターゲット型を `[T]` として `Deref` トレイトを実装しているため、参照外し型強制（deref coercion）のおかげで、`Vec` に対して直接スライスのメソッドを使用できます：

```rust
let numbers = vec![1, 2, 3];
// 驚くべきことに、`iter` は `Vec` のメソッドではありません！
// これは `&[T]` のメソッドですが、参照外し型強制のおかげで
// `Vec` に対して呼び出すことができます。
let sum: i32 = numbers.iter().sum();
```

### メモリレイアウト

`&[T]` は `&str` と同様の**ファットポインタ (fat pointer)** です。\
スライスの最初の要素へのポインタと、スライスの長さ（要素数）で構成されています。

3つの要素を持つ `Vec` があり：

```rust
let numbers = vec![1, 2, 3];
```

そこからスライス参照を作成すると：

```rust
let slice: &[i32] = &numbers[1..];
```

次のようなメモリレイアウトになります：

```text
                    numbers                          slice
         +---------+--------+----------+      +---------+--------+
スタック | pointer | length | capacity |      | pointer | length |
         |    |    |   3    |    4     |      |    |    |   2    |
         +----|----+--------+----------+      +----|----+--------+
              |                                    |  
              |                                    |
              v                                    | 
            +---+---+---+---+                      |
ヒープ:     | 1 | 2 | 3 | ? |                      |
            +---+---+---+---+                      |
                  ^                                |
                  |                                |
                  +--------------------------------+
```

### `&Vec<T>` と `&[T]` の使い分け

関数に `Vec` への不変参照を渡す必要がある場合は、`&Vec<T>` よりも `&[T]` を優先してください。\
これにより、関数は必ずしも `Vec` を背後（バックエンド）に持つものだけでなく、あらゆる種類のスライスを受け入れることができます。

例えば、`Vec` 内の要素の一部（サブセット）を渡すことができます。
しかし、それだけにとどまりません。**配列のスライス**を渡すこともできるのです：

```rust
let array = [1, 2, 3];
let slice: &[i32] = &array;
```

配列のスライスと `Vec` のスライスは同じ型です。どちらも連続した要素の並びへのファットポインタです。
配列の場合、ポインタはヒープではなくスタックを指しますが、スライスを使用する上ではそれは問題になりません。
