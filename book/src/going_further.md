# エピローグ

Rustをめぐる私たちの旅はここで終わりです。\
かなり広範囲にわたる内容でしたが、決して網羅的なものではありません。Rustはカバーする領域が広い言語であり、そのエコシステムはさらに広大です！\
しかし、それに怯える必要はありません。**すべてを学ぶ必要はないのです**。
自分の領域（バックエンド、組み込み、CLI、GUIなど）で成果を出すために必要なことは、**自分のプロジェクトに取り組みながら**自然と身につけていくことができます。

結局のところ、近道はありません。何かが上手くなりたければ、何度も繰り返し実践する必要があります。このコースを通して、あなたはかなりの量のRustコードを書き、言語とその構文が指先に馴染むくらいの経験を積みました。それを「自分のもの」だと感じられるようになるには、さらに多くのコードを書く必要がありますが、練習を続ければ間違いなくその瞬間は訪れます。

## さらなる学習へ

最後に、これからのRustの旅を進めるにあたって役立つと思われる追加のリソースをいくつか紹介して締めくくりましょう。

### 演習問題

[`rustlings`](https://github.com/rust-lang/rustlings) プロジェクトや、[exercism.io](https://exercism.io) のRustトラックで、Rustを練習するためのさらなる演習問題を見つけることができます。

### 入門教材

このコースで扱った同じ概念について別の視点から学びたい場合は、[The Rust Book (The Rust Programming Language)](https://doc.rust-lang.org/book/title-page.html) や [『Programming Rust』](https://www.oreilly.com/library/view/programming-rust-2nd/9781492052586/)をチェックしてみてください。
これらはこのコースとまったく同じトピックを扱っているわけではないので、間違いなく新しい発見があるはずです。Rustの領域はとても広いのです！

### 上級教材

言語についてさらに深く掘り下げたい場合は、[Rustonomicon](https://doc.rust-lang.org/nomicon/) や [『Rust for Rustaceans』](https://nostarch.com/rust-rustaceans)を参照してください。\
[「Decrusted」シリーズ](https://www.youtube.com/playlist?list=PLqbS7AVVErFirH9armw8yXlE6dacF-A6z)も、最も人気のある多くのRustライブラリの内部構造について学ぶのに優れたリソースです。

### 分野別の教材

バックエンド開発にRustを使用したい場合は、[『Zero to Production in Rust』](https://zero2prod.com)をチェックしてください。\
組み込み開発にRustを使用したい場合は、[Embedded Rust book](https://docs.rust-embedded.org/book/)をチェックしてください。

### マスタークラス

分野を横断する重要なトピックに関するリソースもあります。\
テストについては、[「Advanced testing, going beyond the basics」](https://rust-exercises.com/advanced-testing/)をチェックしてください。\
テレメトリについては、[「You can't fix what you can't see」](https://rust-exercises.com/telemetry/)をチェックしてください。
