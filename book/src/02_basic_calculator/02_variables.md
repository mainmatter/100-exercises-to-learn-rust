# 変数 (Variables)

Rustでは、`let` キーワードを使って**変数 (variables)** を宣言できます。\
例えば：

```rust
let x = 42;
```

上記では、変数 `x` を定義し、それに値 `42` を代入しました。

## 型

Rustのすべての変数には型が必要です。型はコンパイラによって推論されるか、開発者によって明示的に指定されるかのいずれかです。

### 明示的な型注釈

変数名の後にコロン `:` と型を続けることで、変数の型を指定できます。例えば：

```rust
// let <変数名>: <型> = <式>;
let x: u32 = 42;
```

上記の例では、`x` の型を `u32` に明示的に制約しています。

### 型推論 (Type inference)

変数の型を指定しない場合、コンパイラはその変数が使用されている文脈に基づいて型を推論しようとします。

```rust
let x = 42;
let y: u32 = x;
```

上記の例では、`x` の型を指定していません。\
`x` は後で、明示的に `u32` と型付けされた `y` に代入されています。Rustは自動的な型強制を行わないため、コンパイラは `x` の型を `y` と同じ `u32` であると推論します。これがエラーなしでプログラムをコンパイルできる唯一の型だからです。

### 推論の限界

コンパイラが、使用方法に基づいて正しい変数の型を推論するために少し手助けを必要とする場合があります。\
そのような場合にはコンパイルエラーが発生し、コンパイラは曖昧さを解消するために明示的な型のヒントを提供するよう求めてきます。

## 関数の引数も変数である

すべてのヒーローがマントを着けているわけではないように、すべての変数が `let` で宣言されるわけではありません。\
関数の引数もまた変数なのです！

```rust
fn add_one(x: u32) -> u32 {
    x + 1
}
```

上記の例では、`x` は `u32` 型の変数です。\
`x` と `let` で宣言された変数の唯一の違いは、関数の引数はその型を**必ず**明示的に宣言しなければならないという点です。コンパイラはそれを推論してくれません。\
この制約により、Rustコンパイラ（そして私たち人間！）は、関数の実装を見なくても関数のシグネチャを理解することができます。これはコンパイル速度の大幅な向上につながります[^speed]！

## 初期化 (Initialization)

変数を宣言するときに、必ずしも初期化する必要はありません。\
例えば：

```rust
let x: u32;
```

これは有効な変数宣言です。\
ただし、変数を使用する前には必ず初期化しなければなりません。初期化せずに使用すると、コンパイラはエラーを出します：

```rust
let x: u32;
let y = x + 1;
```

これは以下のコンパイルエラーになります：

```text
error[E0381]: used binding `x` isn't initialized
 --> src/main.rs:3:9
  |
2 | let x: u32;
  |     - binding declared here but left uninitialized
3 | let y = x + 1;
  |         ^ `x` used here but it isn't initialized
  |
help: consider assigning a value
  |
2 | let x: u32 = 0;
  |            +++
```

[^speed]: コンパイル速度に関しては、Rustコンパイラは得られる限りのあらゆる助けを必要としています。
