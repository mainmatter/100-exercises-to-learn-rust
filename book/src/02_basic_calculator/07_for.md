# ループ (パート2): `for`

カウンタ変数を手動でインクリメント（増加）しなければならないのは少々面倒です。しかも、このパターンは非常に頻繁に登場します！\
これを簡単にするために、Rustは値の範囲を反復処理（イテレート）するより簡潔な方法を提供しています。それが `for` ループです。

## `for` ループ

`for` ループは、イテレータ[^iterator]内の各要素に対してコードブロックを実行する方法です。

一般的な構文は以下の通りです：

```rust
for <要素> in <イテレータ> {
    // 実行するコード
}
```

## 範囲 (Ranges)

Rustの標準ライブラリは、一連の数値を反復処理するために使用できる**範囲 (range)** 型を提供しています[^weird-ranges]。

例えば、1から5までの数値を合計したい場合：

```rust
let mut sum = 0;
for i in 1..=5 {
    sum += i;
}
```

ループが実行されるたびに、コードブロックが実行される前に `i` に範囲内の次の値が代入されます。

Rustには5種類の範囲があります：

- `1..5`：（半開）範囲。1から4までのすべての数値を含みます。最後の値である 5 は含みません。
- `1..=5`：閉区間（両端を含む）範囲。1から5までのすべての数値を含みます。最後の値である 5 も含みます。
- `1..`：終端のない範囲。1から無限大（実際にはその整数型の最大値まで）のすべての数値を含みます。
- `..5`：その整数型の最小値から始まり、4で終わる範囲。最後の値である 5 は含みません。
- `..=5`：その整数型の最小値から始まり、5で終わる範囲。最後の値である 5 も含みます。

開始点が明示的に指定されている最初の3種類の範囲は、`for` ループと一緒に使うことができます。最後の2種類の範囲は他の文脈で使用されますが、それについては後半で扱います。

範囲の両端の値は整数リテラルである必要はありません。変数や式を使うこともできます！

例えば：

```rust
let end = 5;
let mut sum = 0;

for i in 1..(end + 1) {
    sum += i;
}
```
