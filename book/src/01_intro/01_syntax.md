## コメント

単一行コメントには `//` を使うことができます：

```rust
// これは単一行コメントです
// 続けてもう1つの単一行コメントです
```

## 関数

Rustにおける関数は、`fn` キーワードに続けて、関数名、入力パラメータ（引数）、そして戻り値の型を指定して定義します。
関数の本体は波括弧 `{}` で囲みます。

前回の演習では、`greeting` 関数を見ました：

```rust
// `fn` <関数名> ( <入力パラメータ> ) -> <戻り値の型> { <関数本体> }
fn greeting() -> &'static str {
    // TODO: 修正してください 👇
    "I'm ready to __!"
}
```

`greeting` は入力パラメータを持たず、文字列スライスへの参照 (`&'static str`) を返します。

### 戻り値の型

関数が何も返さない場合（つまり、Rustのユニット型である `()` を返す場合）、シグネチャから戻り値の型を省略できます。
`test_welcome` 関数がまさにそうでした：

```rust
fn test_welcome() {
    assert_eq!(greeting(), "I'm ready to learn Rust!");
}
```

上記は以下と等価です：

```rust
// ユニット型の戻り値を明示的に記述した場合
//                   👇
fn test_welcome() -> () {
    assert_eq!(greeting(), "I'm ready to learn Rust!");
}
```

### 値を返す

関数の最後の式は、暗黙的に返されます：

```rust
fn greeting() -> &'static str {
    // これが関数内の最後の式です
    // したがって、その値が `greeting` から返されます
    "I'm ready to learn Rust!"
}
```

`return` キーワードを使って、値を早期に返すこともできます：

```rust
fn greeting() -> &'static str {
    // 行末のセミコロンに注意してください！
    return "I'm ready to learn Rust!";
}
```

可能な限り `return` キーワードは省略するのがRustらしい（イディオマティックな）書き方とされています。

### 入力パラメータ

入力パラメータは、関数名の後に続く丸括弧 `()` の中に宣言します。\
各パラメータは、パラメータ名、コロン `:`、そしてその型の順に宣言します。

例えば、以下の `greet` 関数は、`&str` 型（「文字列スライス」）の `name` パラメータを受け取ります：

```rust
// 入力パラメータ
//        👇
fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}
```

複数の入力パラメータがある場合は、カンマで区切る必要があります。

### 型注釈 (Type annotations)

ここまで何度か「型」という言葉が出てきたので、明確にしておきましょう。Rustは**静的型付け言語 (statically typed language)** です。\
Rustのすべての値には型があり、その型はコンパイル時にコンパイラが把握できていなければなりません。

型は**静的解析 (static analysis)** の一種です。\
型とは、コンパイラがプログラム内のすべての値に貼り付ける**タグ**のようなものだと考えることができます。そのタグに応じて、コンパイラはさまざまなルールを強制できます。例えば、文字列と数値を足すことはできませんが、2つの数値を足し合わせることはできます。
正しく活用すれば、型によって実行時のバグの多くを未然に防ぐことができます。
